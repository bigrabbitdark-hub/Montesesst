# Catálogo de EPI — Anexo I da NR-06 (referência para schema, Montese SST)

> **Origem:** anexado pelo fundador em 2026-08-25, durante o fechamento da
> Fase 6 sub-projeto B (Acesso do técnico parceiro), como material de
> apoio para o próximo sub-projeto pendente da Fase 6: Catálogo de EPI.
> Fonte: NR-06, Ministério do Trabalho e Emprego (texto consolidado,
> Portaria MTP nº 4.219/2022), Anexo I. Preservado aqui como referência
> — o mesmo papel que `docs/reference/modelos-relatorios-sst.md` já
> cumpre para o fluxo de inspeção. **Não implementar nada a partir deste
> documento sem passar pelo ciclo de brainstorm → spec → plano** do
> sub-projeto Catálogo de EPI.

## Uso pretendido

Catálogo oficial dos 93 itens de EPI reconhecidos pelo Anexo I da NR-06,
organizados nas 9 categorias oficiais (A–I). Serve de base para o schema
relacional de catálogo de EPI (CA por equipamento, vínculo
funcionário↔EPI) que já foi adiado três vezes neste projeto (Fase 4A,
Fase 5, Fase 6 sub-projeto A) — ver `docs/reference/modelos-relatorios-sst.md`,
seção 1, para o modelo original de "Relatório de EPIs" que motivou esse
catálogo mais completo.

Cada linha traz: categoria/código do Anexo I, grupo do EPI, descrição
exata do item, o risco específico que ele protege, a NR complementar de
uso comum associada (ex.: NR-35 para itens de altura, NR-10 para choque
elétrico, NR-33 para respiratórios de atmosfera confinada), se CA é
obrigatório, e a base legal.

**Ressalva importante do próprio material, repetida aqui para não se
perder:** a coluna "NR complementar" é uma associação de uso comum, não
texto literal do Anexo I — só a NR-15 é citada explicitamente no Anexo I
(para os protetores auditivos). Confirmar contra o PGR de cada atividade
antes de usar isso como fonte legal direta no produto.

## Notas e glossário (Aba 2 do material original)

- **CA (Certificado de Aprovação):** número emitido pelo Ministério do
  Trabalho e Emprego, exigido para todos os itens listados no Anexo I —
  confirma-se em consultaca.com (ver nota já registrada em
  `docs/reference/modelos-relatorios-sst.md`, seção 1: validade do CA ≠
  vida útil do equipamento, alertar separadamente sobre inspeção/desgaste).
- **Responsabilidades:** empresa fornece, treina o uso e substitui
  quando danificado ou vencido; trabalhador usa corretamente, conserva e
  comunica dano/extravio.
- **Ressalva sobre a coluna "NR complementar":** é associação de uso
  comum entre o tipo de EPI e a norma regulamentadora que trata do risco
  correspondente (ex.: NR-35 para altura, NR-10 para choque elétrico,
  NR-33 para espaço confinado) — **não é texto literal do Anexo I**, com
  a única exceção da NR-15 para protetores auditivos (categoria C), que
  é citada explicitamente. Confirmar contra o PGR de cada atividade
  antes de tratar como fonte legal direta no produto.

## Uso recomendado

Ao desenhar o schema do catálogo de EPI (sub-projeto pendente da Fase
6), usar esta tabela como semente de dados de referência (94 itens após
a linha "não implementar" — na verdade 93, ver contagem acima) e as
